# AccessPath

**An Accessible, Context-Aware Digital Navigation Assistant**

## Problem Statement
People with visual impairments can face barriers when completing multi-step online applications and interpreting charts or tabular information. AccessPath aims to make these workflows more accessible while preserving the user's progress.

## Theme
Software Solutions for People with Disabilities

## Proposed Features
- Keyboard-friendly scholarship application workflow
- Adjustable text size and high-contrast mode
- Browser-based text-to-speech
- Accessible scholarship cutoff charts
- Questions answered using predefined scholarship data
- Progress preservation when navigating between the form and chart

## Technology Stack
- React and Vite
- JavaScript and CSS
- Chart.js and react-chartjs-2
- Papa Parse for CSV processing
- Browser Speech Synthesis API
- Git and GitHub

## Standards Reference
The design will reference BIS IS 17802 (Part 1):2021, subject to verification of the applicable edition and amendments. WCAG 2.2 will be used as a complementary accessibility guideline.

This prototype does not claim formal standards compliance.
